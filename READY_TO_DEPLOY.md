## ⚡ Démarrage 30 secondes

Lisez ceci, c'est tout ce que vous devez savoir pour commencer:

### Étape 1: Supabase (5 min)
1. Allez sur supabase.com → Créez un compte
2. Créez un projet → Copiez l'URL et la clé
3. Allez dans SQL Editor → Exécutez `supabase_migration.sql`

### Étape 2: Config (3 min)
1. Ouvrez `.env.local`
2. Collez vos clés Supabase

### Étape 3: Local (3 min)
1. `npm install`
2. `npm run dev`
3. Testez à http://localhost:3000/public/index.html

### Étape 4: GitHub (10 min)
1. Créez repo GitHub
2. `git init` → `git push`

### Étape 5: Vercel (7 min)
1. Vercel → Importer GitHub
2. Ajouter variables d'env
3. Deploy!

### ✅ Prêt!
Votre site est en ligne! 🎉

Vous pouvez maintenant facilement ajouter:

1. **Authentification**

2. **Upload de fichiers**

